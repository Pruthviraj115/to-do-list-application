# 📝 Task Manager App (Python CLI)

A simple command-line based **Task Manager Application** written in Python. This project allows users to manage their daily tasks efficiently by performing operations like adding, updating, viewing, and deleting tasks.

---

## 🚀 Features

* ✅ Add new tasks
* 🔄 Update existing tasks
* 📋 View all tasks
* ❌ Delete tasks
* 🚪 Exit the application safely
* ⚠️ Handles invalid inputs using exception handling

---

## 🛠️ Technologies Used

* **Python 3**
* Basic concepts:

  * Lists
  * Loops
  * Conditional statements
  * Exception handling

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository or copy the code into a `.py` file.
3. Run the script:

```bash
python task_manager.py
```

---

## 📌 How It Works

1. The program starts by asking the user to enter the number of tasks.
2. User inputs initial tasks.
3. A menu is displayed with the following options:

```
1. ADD
2. UPDATE
3. VIEW
4. DELETE
5. EXIT
```

4. Based on user input:

   * Tasks can be added, updated, viewed, or deleted.
   * The program continues running until the user selects **EXIT**.
